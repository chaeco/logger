为什么是 Logger

为生产环境设计的日志库。

高并发场景不丢日志、不阻塞业务，轮转压缩开箱即用。

◷

文件轮转 + 压缩

按大小轮转、按天数/数量清理，旧文件自动 gzip 压缩，活跃文件永远保留。

const log = new Logger({
  file: { path: './logs', maxSize: 10 * 1024 * 1024,
          maxFiles: 30, maxAge: 30, compress: true },
})
?

异步队列

批量写入 + 定时刷新，block / drop 两种溢出策略，默认不丢日志。

async: {
  enabled: true, queueSize: 5000,
  batchSize: 200, flushInterval: 500,
  overflowStrategy: 'block',
}
!

自动上下文

自动捕获调用方的文件路径与行号，配合 LRU 缓存调用点信息。

logger.error(new Error('DB failed'))
// 输出 JSON 时 Error → {message, name, stack}

用法

从默认实例到完整配置。

直接使用默认 logger，或用 new Logger() 精细控制。

import { logger } from '@chaeco/logger';

// 目录在首次写入时自动创建
logger.info('Application started');
logger.warn('Warning detected', { code: 4001 });
logger.error(new Error('Database connection failed'));

logger.setLevel('silent');  // 一键静默
import { Logger } from '@chaeco/logger';

const logger = new Logger({
  level: 'info',
  name: 'api-service',
  file: {
    path: './logs', maxSize: 10 * 1024 * 1024,
    maxFiles: 30, maxAge: 30, compress: true,
  },
  console: { enabled: true, colors: true, timestamp: true },
  async: { enabled: true, queueSize: 5000,
           batchSize: 200, flushInterval: 500,
           overflowStrategy: 'block' },
  format: { json: true, jsonIndent: 2 },
});
// 优雅关闭：flush 队列 + 关闭句柄（必须 await）
process.on('SIGTERM', async () => {
  await logger.close();
  process.exit(0);
});

// 事件钩子
logger.on('levelChange', (e) => {
  console.log(`Level: ${e.data.oldLevel} → ${e.data.newLevel}`);
});

// 子 logger
const dbLogger = logger.child('db');
dbLogger.info('Connected');  // [api-service:db]

按 QPS 选择参数。
